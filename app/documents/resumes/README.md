# 刘莫昕双语简历后台存档

本目录保存当前网站对应的两份**可编辑 Word 简历**。两份简历均以“智能硬件项目经理”为定位，并与网站中的核心经历、项目、英语能力和海外客户协同表述保持一致。

| 文件 | 语言 | 用途 |
|---|---|---|
| `Liu-Moxin-Smart-Hardware-PM-CN.docx` | 中文 | 中文岗位投递与后续编辑 |
| `Liu-Moxin-Smart-Hardware-PM-EN.docx` | 英文 | 英文岗位投递与海外沟通 |

两份 Word 均采用 A4 两页结构，包含证件照、MindScribe Logo、可点击作品集链接、得力集团工作经历、全英文硕士背景、尼泊尔及其他海外客户协同、云深处四足机器人项目和长期跑步记录。组织名称按当前隐私边界仅写“得力集团”或“Deli Group”，不得恢复内部公司、部门或项目组名称。

Word 文件由时间戳交接目录中的 `scripts/generate_resume_docx.py` 生成。正式 PDF 的 Typst 源文件位于同一交接目录的 `resume-source/`。后续修改应先同步中英文事实，再分别验证 Word 和 PDF 均保持两页。
