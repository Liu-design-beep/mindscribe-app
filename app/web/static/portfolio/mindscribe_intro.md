# 智能笔记助手：灵辑 (Mindscribe)

## 1. 项目概述
**灵辑 (Mindscribe)** 是一款基于大语言模型 (LLM) 的智能笔记管理助手，致力于解决碎片化信息整理难题。它通过自然语言对话交互，智能理解用户意图，自动将笔记内容分类、整理并永久存储在云端，实现从“辅助整理”到“替你整理”的进化。

## 2. 核心功能
*   **🤖 智能对话交互**：支持自然语言添加、查看、切换和创建文档，精准识别用户意图并进行结构化整理。
*   **📝 多文档管理**：支持多文档并行处理与快速切换，实现试用模式与开发模式文档的完全隔离。
*   **☁️ 云端永久存储**：基于 Cloudflare D1 数据库实现数据持久化，支持跨设备无缝访问。
*   **🔐 权限与安全**：内置开发者模式（输入口令解锁）与只读保护机制，确保重要数据安全。
*   **👁️ 沉浸式阅读**：提供弹窗式全屏阅读体验，支持长文档滚动查看与 Markdown 渲染。

## 3. 系统架构 (前后端分离)

本项目采用现代化的前后端分离架构，确保高性能与高可用性：

### 3.1 前端 (Frontend)
*   **托管平台**: Cloudflare Pages
*   **技术栈**: 原生 HTML5/CSS3/JavaScript (无框架依赖，极致轻量)
*   **UI 设计**: 赛博朋克风格 (Cyberpunk Style)，集成故障艺术 (Glitch Art) 与终端交互动效。
*   **职责**: 负责用户界面渲染、交互逻辑处理及静态资源托管。

### 3.2 后端 (Backend)
*   **托管平台**: Render
*   **技术栈**: Python FastAPI
*   **核心服务**:
    *   **API 网关**: 处理 `/api/chat`, `/api/documents` 等请求。
    *   **LLM 集成**: 对接通义千问 (Qwen) 大模型，处理自然语言理解与生成。
    *   **会话管理**: 维护用户上下文与对话状态。

### 3.3 数据存储 (Database)
*   **平台**: Cloudflare D1 (基于 SQLite 的边缘数据库)
*   **策略**:
    *   **试用数据**: 临时存储，定期清理。
    *   **开发者数据**: 永久持久化存储。

## 4. 技术亮点
*   **混合云部署**: 结合 Cloudflare 的边缘计算能力与 Render 的容器化服务能力，实现全球加速与灵活扩展。
*   **RAG (检索增强生成)**: 利用向量检索技术，让 AI 基于用户已有的笔记库进行回答，减少幻觉。
*   **混沌缓冲区 (Chaos Box)**: 创新的“丢入即忘”交互理念，用户只需输入，整理工作全权交给 AI 后台异步处理。

## 5. 开发与部署流程
1.  **代码提交**: GitHub 仓库触发 CI/CD 流水线。
2.  **前端构建**: Cloudflare Pages 自动拉取代码，运行构建脚本，发布静态资源。
3.  **后端部署**: Render 自动检测更新，重新构建 Docker 容器并上线服务。
