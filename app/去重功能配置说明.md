# LLM 去重功能配置说明

## ⚠️ 重要提示

**去重功能需要在阿里云百炼应用中更新系统提示词才能生效！**

本地代码已经完成，但系统提示词需要在阿里云百炼控制台中手动更新。

---

## 📋 配置步骤

### 1. 登录阿里云百炼控制台

1. 访问 [阿里云百炼控制台](https://dashscope.console.aliyun.com/)
2. 登录您的账号
3. 进入"应用管理"或"智能体应用"

### 2. 找到您的应用

找到您正在使用的应用（APP_ID 对应的应用）

### 3. 更新系统提示词

1. 点击应用进入详情页
2. 找到"系统提示词"或"Prompt"配置
3. 打开 `程序/SYSTEM_PROMPT_COMPLETE.md` 文件
4. **复制整个文件内容**（从第1行到第717行）
5. **粘贴到阿里云百炼应用的系统提示词配置中**
6. 保存配置

### 4. 验证配置

1. 重启后端服务器
2. 刷新前端页面
3. 在同一个会话中（不刷新页面）：
   - 第1次：输入内容A
   - 第2次：再次输入内容A（应该立即检测到重复并显示警告）
4. 应该看到警告："⚠️ 检测到重复内容，不进行添加"

## 🔍 调试方法

### 检查对话历史

后端日志会显示：
```
[对话历史] 当前对话历史信息
[对话历史] 消息总数: X
[对话历史] 最近三次用户输入数量: X
[对话历史] 用户输入 #1: ...
[对话历史] 用户输入 #2: ...
[对话历史] 用户输入 #3: ...
[对话历史] 当前用户输入: ...
```

### 检查 LLM 响应

后端日志会显示：
```
[LLM原始响应] LLM 完整原始返回内容（JSON解析之前）:
```

如果看到 `"intent_type": "DUPLICATE_CONTENT"`，说明去重功能正常工作。

## ❓ 常见问题

### Q1: 为什么去重功能没有生效？

**A:** 最可能的原因是系统提示词还没有在阿里云百炼应用中更新。请按照上述步骤更新系统提示词。

### Q2: 每次刷新页面后，去重功能失效？

**A:** 这是正常的。每次刷新页面会创建新的会话，对话历史会被重置。去重功能只在同一个会话中有效。

### Q3: 如何测试去重功能？

**A:** 
1. 确保系统提示词已更新
2. 在同一个会话中（不刷新页面）
3. 第1次输入内容A
4. 第2次再次输入内容A（应该立即检测到重复并显示警告）
5. 或者：第1次输入A，第2次输入B，第3次输入C，第4次再次输入A（应该检测到与第1次重复）

### Q4: 去重功能检查多少次对话历史？

**A:** 检查最近三次用户输入。如果当前输入与这三次中的**任何一次**完全相同，会被立即检测为重复并阻止添加。**不需要等到输入三次重复内容才检测，第二次输入重复就应该被检测到。**

## 📝 系统提示词更新位置

系统提示词需要更新的部分（在文件开头）：

```markdown
## 内容去重规则

**重要：在识别意图前，您必须检查当前用户输入是否与对话历史中最近三次用户输入中的任意一次完全相同。**

**检查规则：**
1. 查看您的对话历史中最近的三次用户输入（如果对话历史少于三次，则查看所有历史输入）
2. 将当前用户输入与这三次输入的内容逐一比较
3. 如果发现当前输入与其中任意一次输入完全相同，**立即**返回 DUPLICATE_CONTENT 意图，不执行 ADD 操作
4. 如果没有重复，继续正常的意图识别

**重要说明：**
- 只要当前输入与最近三次输入中的任意一次重复，就应该立即检测并阻止
- **不需要等到输入三次重复内容才检测，第二次输入重复就应该被检测到**
- 例如：第1次输入内容A，第2次输入内容B，第3次输入内容C，第4次再次输入内容A → 应该在第4次就检测到与第1次重复

...（完整内容见 SYSTEM_PROMPT_COMPLETE.md）
```
