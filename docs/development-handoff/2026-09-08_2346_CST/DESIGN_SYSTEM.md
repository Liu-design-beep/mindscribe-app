# MindScribe 双语简历作品集设计系统

## 设计定位

当前界面采用**瑞士工程档案风格**。它不是通用科技公司落地页，也不是传统时间线简历。页面通过大号编号、工程网格、强对比色块、纸张质感和实拍证据建立“能够进入技术现场的智能硬件项目经理”形象。

MindScribe 品牌承担双重角色。第一层是原智能笔记产品留下的视觉身份。第二层是刘莫昕的个人产品与项目档案。原 Logo、加载图标、浏览器图标和英文品牌名 MindScribe 必须保留。[1]

## 品牌与色彩

| 变量 | 色值 | 主要用途 |
|---|---:|---|
| `--ink` | `#151a23` | 主文本、深色线条 |
| `--navy` | `#0c1628` | 工作经历、跑步与简历区域的深色背景 |
| `--blue` | `#0647f5` | 主行动按钮、编号、焦点与技术强调 |
| `--orange` | `#ff5c35` | 少量高优先级强调与联系区 |
| `--paper` | `#fffdf7` | 卡片、弹窗与浅色内容背景 |
| `--ivory` | `#f2efe7` | 全站纸张底色 |
| `--line` | `#cbc6bc` | 工程网格、卡片分隔线 |
| `--muted-text` | `#626a77` | 次级说明与元数据 |

页面背景使用低对比度径向渐变和固定噪点纹理。纹理存在感应弱于正文，不得把噪点放大为明显颗粒。深色区域以海军蓝为底，正文使用浅灰而不是纯白，以减少长页面的视觉疲劳。

## 字体与信息层级

正文使用 `IBM Plex Sans` 与 `Noto Sans SC`。展示标题、编号、数据和品牌英文字段使用 `Space Grotesk`。中文标题必须保留紧凑字距与明显粗细差异。页面不应退化为单一 Inter 字体和统一字重。

章节标题采用跨行大标题，英文 kicker 使用 `SECTION / NN` 形式。编号既是导航线索，也是视觉节奏。正文行宽应受控，说明性段落不应横跨整个屏幕。

## 布局原则

桌面端最大内容宽度为 1380px，采用不对称双栏、十二列项目网格和局部 sticky 内容。深色经历区左侧负责定位陈述，右侧负责时间线与实拍证据。成果卡使用严谨边框而不是大量圆角。项目卡既包含技术信息，也通过真实封面和视频提供证据。

移动端在 900px 以下收束为单栏，在 640px 以下进一步调整字号、图片比例和卡片网格。产品实拍宽卡在手机上转为两列图片，不得产生横向滚动。导航在移动端变为可关闭的顶部菜单。

## 交互规范

语言按钮必须切换页面全部文本、浏览器标题、按钮标签、项目详情和下载简历版本。项目筛选应保持当前类别的明显选中态。项目详情使用可键盘关闭的 Dialog。视频使用原生控制条和封面，不自动播放。按钮按下反馈约 160ms，常规过渡控制在 300ms 内，并尊重 `prefers-reduced-motion`。

## 图片与媒体

产品白底图使用 `object-fit: contain`，避免裁掉机身。结构、量产和日常工作实拍使用 `object-fit: cover`，但不得裁掉主要设备。全英文课堂照片、证件照和跑步记录属于个人可信度证据，不得用生成图替换。项目视频必须保留封面和清晰的播放入口。

WebDev 中的大媒体使用 `/manus-storage/`。正式部署时替换为 `/portfolio-assets/`，并通过 `_headers` 设置缓存。每次替换简历 PDF 应使用新的版本化文件名，避免 CDN 和浏览器复用旧文件。

## 内容与隐私边界

公司名称只保留“得力集团”或“Deli Group”。不得公开内部公司、部门或项目组名称。全英文硕士背景、英语成绩和海外客户沟通是核心差异化，不能下沉为普通补充项。未在来源资料中拆分个人职责的团队项目，必须明确标注团队边界。
