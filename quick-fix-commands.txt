快速修复命令（在项目目录中执行）：

1. 配置安全目录：
   git config --global --add safe.directory "I:/简历/展示整理12.13/灵辑/程序 (2)"

2. 然后继续执行：
   git add .
   git commit -m "Initial commit: 灵辑应用 - 前后端分离架构"
   git branch -M main
   git remote add origin https://github.com/Liu-design-beep/mindscribe-app.git
   git push -u origin main

或者直接运行修复脚本：
   fix-git-safe-directory.bat
