# 如何查看网页错误信息

## 方法一：使用快捷键（最简单）

1. **打开网页后，直接按 `F12` 键**
   - 这会打开浏览器的"开发者工具"

2. **点击 "Console"（控制台）标签页**
   - 通常在开发者工具的顶部或底部

3. **查看错误信息**
   - 🔴 **红色文字** = 错误信息
   - ⚪ **白色文字** = 正常的调试信息（可以忽略）
   - ⚠️ **黄色文字** = 警告信息

## 方法二：右键菜单

1. **在网页上右键点击**
2. **选择"检查"或"Inspect"**
3. **点击 "Console" 标签页**

## 方法三：浏览器菜单

### Chrome浏览器：
- 点击右上角三个点 `⋮`
- 选择"更多工具" → "开发者工具"

### Edge浏览器：
- 点击右上角三个点 `⋯`
- 选择"更多工具" → "开发者工具"

## 常见错误类型

### 1. 网络错误（红色）
```
Failed to fetch
Network error
CORS error
```
**含义**：无法连接到后端服务器

### 2. JavaScript错误（红色）
```
Uncaught TypeError: ...
Cannot read property '...' of undefined
```
**含义**：代码执行出错

### 3. 404错误（红色）
```
404 Not Found
```
**含义**：找不到文件或API接口

## 如何截图错误信息

1. 打开开发者工具的 Console 标签页
2. 找到红色的错误信息
3. 按 `Print Screen` 键截图
4. 或者右键点击错误信息 → "Copy"（复制）
